# o-motion-skill

用模板做视频：给一个模板、填好内容、指定输出文件名，就能拿到一条成片 mp4。
画面尺寸、帧率、渲染、成品校验都由工具自动处理，你不需要懂渲染。

## 能做什么

| 模板类型 | 你手上有什么 | 能得到什么 |
|---|---|---|
| `.motion` 模板 | 一个 `.motion` 文件 + 要填的文字/参数 | 成片 mp4（画面规格按模板自带设定） |
| 网页模板目录 | 一个含 `_render` 子目录的模板文件夹 + 素材与时长 | 成片 mp4（尺寸、时长由你指定） |

工具会自动挑对渲染方式，并在出片后检查成品（能否正常播放、分辨率对不对、时长对不对、有没有音轨）。
检查不通过就不交付，并告诉你哪一项没过、怎么改。

## 安装

1. **Python 3.9 或更高版本**
2. **渲染引擎**：把这套工具的引擎放在本工具同级目录，或设置环境变量 `MOTION_CORE_DIR` 指向它
   （引擎目录里应能看到 `core/invoke.py`）
3. 只有用**网页模板目录**时，才额外需要：Node.js 22+、Chrome、FFmpeg、ffprobe

先跑一次预检，确认环境就绪：

```bash
python render.py --template ./模板目录 --end 1 --probe --output unused.mp4
```

## 快速开始

**用 `.motion` 模板**（推荐把参数写成文件，避免终端吃掉引号）：

```bash
python render.py --template ./模板/口播讲解.motion \
    --params-file ./内容.json --output ./out/第一条.mp4
```

内容文件就是一个普通 JSON：

```json
{"title": "开场标题", "subtitle": "副标题", "body": "正文内容"}
```

参数名以模板作者给出的说明为准。想快速看模板需要哪些参数，可以只跑解析：

```bash
python render.py --template ./模板/口播讲解.motion --output ./out/probe.mp4 --verbose
```

**用网页模板目录**：

```bash
python render.py --template ./模板/海边电影感-竖屏 \
    --end 12 --width 1080 --height 1920 --fps 60 \
    --audio ./配音.wav --output ./out/海边.mp4
```

- `--end` 是成片总时长（秒），网页模板必须给，具体数值见模板目录里的 README
- 竖向视频把宽高写成 1080×1920，横幅写 1920×1080
- 配音或背景音通过 `--audio` 传入 wav
- 模板自带的渲染模块会被自动找到，一般不用手填

## 常用选项

| 选项 | 作用 |
|---|---|
| `--params-file` | 从 JSON 文件读参数（推荐） |
| `--params` | 参数直接写在命令行（只有一两个参数时用） |
| `--output` | 成片路径。**文件已存在会拒绝执行**，不会覆盖你的旧文件 |
| `--probe` | 只检查环境，不生成视频 |
| `--verbose` | 显示底层执行的命令和详细报错 |
| `--json` | 输出完整 JSON 结果，方便接到别的程序里 |
| `--core-dir` / `MOTION_CORE_DIR` | 指定渲染引擎位置（自动找不到时才需要） |

## 出错了怎么办

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 找不到渲染引擎 | 引擎没放到位或没设环境变量 | 设置 `MOTION_CORE_DIR`，或用 `--core-dir` 指定 |
| 这台电脑缺少渲染所需的组件 | 网页模板链路依赖不全 | 按提示装 Node.js / Chrome / FFmpeg 后重试 |
| 输出文件已存在 | 工具不覆盖已有文件 | 换个输出文件名，例如加 `_v2` |
| 模板读取失败 | 模板文件不完整或不是 `.motion` | 重新下载模板；确认文件没被改名 |
| 这个模板缺少可渲染的入口 | 模板包不完整 | 换一个模板 |
| 这个目录不是可直接渲染的模板 | 指向了目录，但它不是网页模板 | `.motion` 请直接指向文件；网页模板需含 `_render/render_project.mjs` |
| 成品没通过检查 | 内容超长、画面静止、时长对不上等 | 按列出的原因调参数；模板自身问题就换模板 |
| 参数文件不是合法 JSON | 少了引号或多了一个逗号 | 用 JSON 校验工具检查一遍 |

报错信息末尾都会有一行「怎么办」，照着做即可。

## 模板从哪来

模板由模板库或平台提供，两种形态：

- **`.motion` 文件**：单个文件，参数以模板作者说明为准
- **网页模板目录**：一个文件夹，内含 `_render`（渲染器）、素材、以及一份说明用法的 README

下载模板后不用改任何代码，直接指向它就能用。

## 已知限制

- `.motion` 模板的画面尺寸和帧率由模板自身决定，不能改。想要别的画幅请换对应模板
- 网页模板目录必须自带 `_render/render_project.mjs`（渲染器），否则无法出片
- 网页模板缺少一份 `motion.json` 元数据时会出一条提醒，属正常现象，不影响出片
- 参数名与模板强绑定，填错名字不会报错，只会呈现为空内容 —— 请按模板说明的字段名填写
