# o-motion-skill

用模板做视频：给一个模板、填好内容、指定输出文件名，就能拿到一条成片 mp4。
画面尺寸、帧率、渲染、成品校验都由工具自动处理，你不用懂渲染。

## 能做什么

| 模板类型 | 你手上有什么 | 能得到什么 |
|---|---|---|
| `.motion` 模板 | 一个 `.motion` 文件 + 要填的文字 | 成片 mp4（画幅与时长由模板决定） |
| 网页模板目录 | 一个含 `_render` 的模板文件夹 + 素材 | 成片 mp4（画幅与时长由你指定） |

工具会自动挑对渲染方式，并在出片后检查成品（能否正常播放、分辨率对不对、时长对不对、有没有音轨）。
**检查不通过就不交付**，并告诉你哪一项没过、怎么改。

## 安装

1. **Python 3.9 或更高版本**
2. **渲染引擎**：放在本工具同级目录，或设置环境变量 `MOTION_CORE_DIR` 指向它
   （引擎目录里能看到 `core/invoke.py`）
3. 只有用**网页模板目录**时，才额外需要：Node.js 22+、Chrome、FFmpeg，
   以及浏览器渲染模块 `playwright-core`（工具会自动查找；找不到时在模板目录执行
   `npm install playwright-core`，或用 `--playwright-module` 指定它的位置）

确认环境就绪（只自检，不出片）：

```bash
python render.py --template ./模板/口播讲解.motion --probe
```

## 快速开始

### 用 `.motion` 模板

**第一次用某个模板，先让它给你一份参数文件**——不用猜字段名：

```bash
python render.py --template ./模板/口播讲解.motion --init-params ./内容.json
```

它会从模板里取出一份**可以直接跑通**的参数，存成 `内容.json`。打开这个文件，
把里面的文字换成你的内容即可。

然后出片：

```bash
python render.py --template ./模板/口播讲解.motion \
    --params-file ./内容.json --output ./out/第一条.mp4
```

参数名由模板固定，`--init-params` 已经按模板要求列全了，照着改文字就行。
（为什么不建议手写：模板对字段是**严格校验**的，多一个它不认识的字段就会直接报错。）

想改文字后连出多条，复制一份参数文件改内容即可。

### 用网页模板目录

```bash
python render.py --template ./模板/海边电影感-竖屏 \
    --end 12 --width 1080 --height 1920 --fps 60 \
    --audio ./配音.wav --output ./out/海边.mp4
```

- `--end` 是成片总时长（秒），网页模板必须给，具体数值见模板目录里的 README
- 竖屏写 1080×1920，横屏写 1920×1080
- 配音或背景音用 `--audio` 传 wav
- 模板自带的渲染模块会被自动找到，一般不用手填

## 常用选项

| 选项 | 作用 |
|---|---|
| `--init-params` | 从模板生成一份可填写的参数文件（推荐第一步） |
| `--params-file` | 指定参数文件出片 |
| `--params` | 参数直接写在命令行（只有一两个参数时用） |
| `--output` | 成片路径。**已存在会拒绝执行**，不会覆盖你的旧文件 |
| `--probe` | 只检查环境，不出片 |
| `--verbose` | 显示底层命令和完整报错 |
| `--json` | 输出完整 JSON，方便接到别的程序里 |
| `--core-dir` / `MOTION_CORE_DIR` | 指定渲染引擎位置（自动找不到时才需要） |

## 出错了怎么办

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 找不到渲染引擎 | 引擎没放到位或没设环境变量 | 设 `MOTION_CORE_DIR`，或用 `--core-dir` 指定 |
| 这台电脑缺少渲染所需的组件 | 网页模板链路依赖不全 | 按提示装 Node.js / Chrome / FFmpeg |
| 需要一个浏览器渲染模块 `playwright-core` | 模板目录里没装这个模块 | 在模板目录执行 `npm install playwright-core`，或用 `--playwright-module` 指定已有位置 |
| 输出文件已存在 | 工具不覆盖已有文件 | 换输出文件名，例如加 `_v2` |
| 参数里有模板不认识的字段 | 手写参数带了多余字段 | 删掉它列出的字段，或先用 `--init-params` 生成骨架 |
| 缺少必填参数 | 参数文件少了一项 | 用 `--init-params` 生成的骨架补齐 |
| 这个模板缺少可渲染的入口 | 模板包不完整 | 换一个模板 |
| 这个目录不是可直接渲染的模板 | 指向了目录但它不是网页模板 | `.motion` 直接指向文件；网页模板需含 `_render/render_project.mjs` |
| 成品没通过检查 | 内容超长、画面静止、时长对不上等 | 按列出的原因调参数；模板自身问题就换模板 |
| 参数文件不是合法 JSON | 少了引号或多了一个逗号 | 用 JSON 校验工具检查一遍 |

报错都会给出一行「怎么办」，照着做即可；加 `--verbose` 可看到完整技术细节。

## 模板从哪来

模板由模板库或平台提供，两种形态：

- **`.motion` 文件**：单个文件，自带参数示例，用 `--init-params` 取出来即可
- **网页模板目录**：一个文件夹，内含 `_render`（渲染器）与一份说明用法的 README

拿到模板不用改代码，直接指向它就能用。

## 已知限制

- `.motion` 模板的画幅和帧率由模板自身决定，不能改；要别的画幅请换对应模板
- 网页模板目录必须自带 `_render/render_project.mjs`，否则无法出片
- 网页模板还需要 `playwright-core` 这个浏览器渲染模块，模板通常不自带
- 模板对参数是严格校验：多一个不认识的字段就报错，不会静默忽略
- 同一模板重复出片请换输出名，工具不覆盖已有文件（刻意设计）
