# o-motion-skill

把现成的模板做成视频。你只需要准备素材和内容，剩下的交给平台 AI。

## 三步

### 1. 准备素材和内容

- **模板**：一个 `.motion` 文件，或一个带 `_render` 的网页模板目录
- **内容**：文案、配音 wav、图片/视频素材（按模板要求，缺什么 AI 会告诉你）
- **成片名**：想好输出文件名

### 2. 把模板和开工提示词一起丢给平台 AI

复制下面这段，把尖括号里的内容换成你的实际信息：

```text
用 o-motion-skill 帮我把这个模板做成视频。

模板：<模板文件的完整路径，或模板目录路径>
素材：<素材文件夹路径，或"还没有，你先告诉我需要什么">
内容：<文案直接写在这里，或"文案在我给的文档里">
输出：<想要的成片路径和文件名>

要求：
1. 参数不要让我手填，你按模板要求生成参数骨架，我只负责改文字。
2. 出片前先自检环境，缺组件提前告诉我。
3. 成品检查不通过就不要交付，直接说明哪一项没过、怎么改。
4. 不要覆盖同名文件。
```

### 3. 按 AI 的交互指引照做

AI 会依次找你确认：文字内容对不对、要不要配音、画面比例、输出文件名。照着答就行，不需要懂渲染参数。

## 它保证什么

- **自动选渲染方式**：`.motion` 走引擎整链，网页模板走模板自带渲染器，你不用区分
- **出片前先查环境**：缺 Node.js / Chrome / FFmpeg 时提前拦下，不会渲到一半才失败
- **出片后自动校验**：能否正常播放、分辨率对不对、时长对不对、该有的音轨在不在
- **不合格不交付**：明确列出哪项没过、怎么改，改好了再出片
- **不覆盖旧文件**：同名输出会被拒绝，避免误删你上一条成片
